# Hangman Game (C++)

## Overview
A console-based Hangman game developed in C++ as part of my programming fundamentals journey.  
Built to strengthen logic, control flow, and problem-solving—no frameworks, just fundamentals.

## Features
- Random word selection
- Limited number of attempts
- Visual hangman stages
- Input validation

## Concepts & Skills Applied
- Loops and conditional statements
- Functions
- Arrays and strings
- Random number generation
- Basic game logic
- Clean console I/O handling

## How to Run
Compile and run using any standard C++ compiler:
```bash
g++ hangman.cpp -o hangman
./hangman
